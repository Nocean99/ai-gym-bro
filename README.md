# 🏋️ AI Gym Bro

An intelligent workout tracking app with a conversational AI personal trainer that remembers everything and gives honest, personality-filled feedback.

## Features
- 🤖 **Natural Language Processing**: Log workouts by talking naturally
- 📊 **Intelligent Recommendations**: AI analyzes your history
- 🎯 **Performance Tracking**: Automatic PR detection
- 💬 **Conversational AI**: Ask questions naturally
- 🔥 **Personality**: Arnold quotes, gym memes, and honest feedback

## Tech Stack
- **Backend**: Python Flask REST API
- **AI**: OpenAI GPT-4
- **Database**: PostgreSQL
- **Mobile**: React Native (coming soon)
